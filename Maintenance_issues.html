How to read this. Each row is one distinct issue drawn from the maintenance@ mailbox; dates are when it was first raised and status is the latest seen in that email thread. Not marked resolved means the latest email in the thread does not show a clearly resolved status (replaced, repaired, fixed, cleared). Most jobs never had a closure emailed, so this is an upper bound that includes many older items almost certainly completed; the recent end of the list is the real worklist. Time windows are measured back from the latest issue in the data (5 Oct 2026). Children's names are replaced with YP, and addresses and vehicle registrations are removed from this shared copy. A working picture from email traffic, not an audited register.
